# Условия использования

Дата публикации: 07 августа 2026 года

Настоящая Политика конфиденциальности регулирует порядок обработки и защиты персональных данных пользователей сайта **[Название сервиса]** (далее — «Сервис»).

Используя Сервис, пользователь подтверждает свое согласие с условиями настоящей Политики конфиденциальности.

---

## 1. Общие положения

1.1. Администрация Сервиса уважает право пользователей на конфиденциальность и принимает необходимые меры для защиты персональных данных.

1.2. Настоящая Политика разработана в соответствии с применимым законодательством о защите персональных данных.

1.3. Политика распространяется на информацию, которую Сервис получает от пользователей при:

- регистрации учетной записи;
- использовании функций сайта;
- создании и редактировании цифровых страниц;
- оформлении заказов и оплате услуг;
- обращении в службу поддержки.

---

# 2. Какие данные мы собираем

В зависимости от использования Сервиса могут обрабатываться следующие категории данных:

## 2.1. Данные учетной записи

При регистрации пользователь может предоставить:

- имя пользователя;
- адрес электронной почты;
- пароль в защищенной форме;
- иные данные, необходимые для работы учетной записи.

## 2.2. Данные цифровых страниц

При использовании функциональности Сервиса пользователь может самостоятельно добавлять:

- фотографии;
- текстовые материалы;
- биографическую информацию;
- даты событий;
- ссылки;
- комментарии и сообщения;
- другие материалы, которые пользователь считает необходимыми.

Пользователь самостоятельно определяет содержание размещаемой информации и уровень доступа к ней.

## 2.3. Технические данные

Автоматически могут собираться:

- IP-адрес;
- тип браузера;
- информация об устройстве;
- дата и время посещения;
- данные о взаимодействии с сайтом;
- технические журналы работы системы.

Эти данные используются исключительно для обеспечения безопасности, стабильной работы и улучшения качества Сервиса.

---

# 3. Цели обработки персональных данных

Персональные данные используются для следующих целей:

- предоставление доступа к функциональности Сервиса;
- создание и управление учетной записью пользователя;
- хранение пользовательского контента;
- обработка платежей;
- предоставление технической поддержки;
- отправка уведомлений, связанных с работой Сервиса;
- предотвращение мошеннических действий;
- улучшение качества и безопасности Сервиса.

---

# 4. Основания обработки данных

Обработка персональных данных осуществляется на следующих основаниях:

- согласие пользователя;
- необходимость исполнения договора на предоставление услуг;
- выполнение требований законодательства;
- обеспечение законных интересов Администрации Сервиса, включая защиту инфраструктуры и предотвращение нарушений.

---

# 5. Хранение и защита данных

5.1. Администрация Сервиса принимает технические и организационные меры для защиты данных пользователей от:

- несанкционированного доступа;
- изменения;
- удаления;
- распространения;
- иных неправомерных действий.

  5.2. Данные хранятся в течение срока, необходимого для предоставления услуг, выполнения обязательств перед пользователем и соблюдения требований законодательства.

  5.3. После прекращения необходимости обработки данные могут быть удалены или обезличены.

---

# 6. Передача данных третьим лицам

Администрация Сервиса не продает и не передает персональные данные пользователей третьим лицам без законных оснований.

Передача данных возможна в следующих случаях:

- пользователь дал согласие на такую передачу;
- передача необходима для предоставления услуги;
- этого требует законодательство;
- необходимо защитить права и безопасность Сервиса или пользователей.

Для работы отдельных функций могут использоваться сторонние сервисы:

- платежные системы;
- сервисы хранения файлов;
- сервисы отправки уведомлений;
- аналитические инструменты.

Такие организации могут обрабатывать данные только в объеме, необходимом для выполнения соответствующих функций.

---

# 7. Платежные данные

Оплата услуг может осуществляться через сторонние платежные сервисы.

Администрация Сервиса не получает и не хранит полные данные банковских карт пользователей.

Обработка платежной информации осуществляется соответствующими платежными организациями согласно их правилам обработки данных.

---

# 8. Права пользователя

Пользователь имеет право:

- получать информацию об обработке своих персональных данных;
- изменять предоставленные данные;
- удалить учетную запись;
- запросить удаление персональных данных;
- ограничить обработку данных в предусмотренных законом случаях;
- отозвать согласие на обработку данных.

Для реализации прав пользователь может обратиться по адресу:

**Email:** [адрес электронной почты поддержки]

# 9. Пользовательский контент

9.1. Пользователь самостоятельно несет ответственность за материалы, которые размещает в Сервисе.

9.2. Пользователь обязан иметь необходимые права и разрешения на размещение загружаемых материалов.

9.3. При использовании функций совместного доступа пользователь самостоятельно определяет круг лиц, которым предоставляется доступ к информации.

---

# 10. Использование файлов cookie

Сервис может использовать файлы cookie и аналогичные технологии для:

- авторизации пользователей;
- сохранения настроек;
- анализа работы сайта;
- повышения удобства использования.

Пользователь может ограничить использование cookie через настройки своего браузера.

---

# 11. Изменение Политики конфиденциальности

Администрация Сервиса имеет право изменять настоящую Политику.

Новая версия Политики вступает в силу с момента ее публикации на сайте, если иное не указано дополнительно.
